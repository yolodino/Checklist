TRADE CHECKLIST PWA

WHAT'S INCLUDED
- 10-item 4H / macro / 15M checklist
- Checklist turns fully green when all 10 items are checked
- Each transition to 10/10 is recorded with a timestamp
- Reset starts a fresh setup without deleting the journal
- Export completed setups as CSV
- Local storage and offline support after first load

HOW TO RUN
A PWA must be served from HTTPS (or localhost). It will not install reliably by opening index.html directly.

EASIEST OPTION: GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. In the repository, open Settings -> Pages.
4. Set deployment source to "Deploy from a branch", choose main and /(root), then Save.
5. Wait for the published HTTPS URL.
6. Open that URL on your phone.
7. iPhone: Share -> Add to Home Screen.
   Android: browser menu -> Install app / Add to Home screen.

DATA
The checklist and journal are saved in that browser on that device. They are not synced between devices. Export the journal regularly if you want a separate backup. Clearing browser website data will remove the locally saved journal.
